# v0.3.0 — Chinese plugin-store localization: 3,075 description pairs

The first public source release of **Codex Plugin Store Localizer**, a local-first launcher for Chinese translation and multilingual localization of the built-in Codex / ChatGPT desktop plugin directory.

## Included

- 15 locale codes; Simplified Chinese includes the expanded catalog snapshot.
- As of September 2026: 3,075 short-description pairs, 3,078 long-description pairs, and 12,487 plugin-text entries. These are entries, not unique plugin counts.
- Other locale packs cover the store shell and six Popular cards. Unknown strings remain English.
- macOS launcher and experimental Windows `.cmd` launcher.
- Private Chromium CDP pipe, exact source-text matching, schema-validated local data, and no app-file patching or TCP debugging port.

## Download and run

Download **codex-plugin-store-localizer-v0.3.0.zip** and extract it. This is a **source bundle**, not a signed installer or a copy of the official app. Use Python 3.11; Windows commands use `py -3.11` instead of `python3`.

```bash
python3 scripts/manage.py locale zh-Hans
python3 scripts/manage.py install
```

Save your work, fully quit the desktop app, and use the installed **ChatGPT 插件商店汉化版** launcher. Open the plugin directory, then run `python3 scripts/manage.py status` and verify the actual text. Installation alone does not prove localization is active.

The ZIP's SHA-256 checksum is provided in **SHA256SUMS.txt**. Compare it after downloading with `shasum -a 256` on macOS or `Get-FileHash -Algorithm SHA256` in PowerShell. A checksum detects a mismatched download; it is not an independent signature.

## Known limitations and safety

- Windows real-device UI acceptance is pending; automated CI is not a native compatibility guarantee.
- Windows checks Authenticode validity but does not pin the publisher. Only use an official trusted app binary.
- macOS requires the expected app identity and full integrity. Do not bypass a failed signature check.
- Coverage is based on the bundled snapshot; new catalog entries and source changes can remain English.
- This independent community project is not affiliated with OpenAI. It does not translate chat content.
