Start locally

  1. 1. Choose your language
    python3 scripts/manage.py locale zh-Hans
  2. 2. Install, then relaunch
    python3 scripts/manage.py install

    Save your work and fully quit the desktop app first, then use the installed launcher. On Windows replace python3 with py -3.11.

Download and extract the source ZIP first, then enter its folder. The macOS wrapper requires /usr/bin/python3. Verify status and actual page text; installation alone is not runtime proof.
