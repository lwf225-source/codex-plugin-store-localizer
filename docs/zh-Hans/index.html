在本地开始

  1. 1. 选择语言
    python3 scripts/manage.py locale zh-Hans
  2. 2. 安装并重新启动
    python3 scripts/manage.py install

    先保存工作并完全退出桌面应用，再使用安装好的启动器。Windows 将 python3 替换为 py -3.11。

先下载并解压源码 ZIP，再进入项目目录。macOS 启动器需要 /usr/bin/python3。安装不等于页面已生效，请核对 status 与实际文字。
